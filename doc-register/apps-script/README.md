# เติมทะเบียนเอกสารอัตโนมัติ (อ่านรูปจาก Slack → ลง Google Sheets)

ตัวช่วยกรอกชีต **"รายการรับ-ส่งเอกสาร พัสดุ ประจำวัน"** แท็บ `รายการรับเอกสารภายนอกWH300`
ไม่มีเซิร์ฟเวอร์ ไม่มีแอปใหม่ ไม่ต้องให้ใครเปลี่ยนวิธีทำงาน

## ทำงานยังไง

```
Admin ถ่ายรูปซองลง Slack        ทุก 5 นาที ระบบจะ                    ทีม GM
ห้อง #parcel-opr           →    ไปหยิบรูปใหม่จาก Slack          →    เปิดชีต
(เหมือนเดิมทุกอย่าง)             อ่านรูปด้วย Claude                     ดูแถวใหม่ท้ายตาราง
ไม่ต้องทำอะไรเพิ่ม                เติมแถวใหม่ในชีต                      แก้เฉพาะช่องที่ระบายสี
                                เก็บสำเนารูปไว้ใน Drive
```

งานของทีม GM เปลี่ยนจาก **พิมพ์ 6 ช่องต่อ 1 ซอง** เป็น **อ่าน 1 แถว + แก้ช่องที่ระบายสี**

## ระบบจะเติมช่องไหนให้บ้าง

| ช่องในชีต | ระบบเติมให้ | หมายเหตุ |
|---|---|---|
| ลำดับที่ | ✅ | ต่อจากเลขล่าสุดในชีต |
| วันที่รับเอกสาร/พัสดุ | ✅ | วันที่ระบบอ่านรูป |
| ประเภทเอกสาร | ✅ | ชนิดซอง เช่น ซองจดหมาย ซองน้ำตาล |
| เลข tracking / เลข INV | ✅ | ไม่มี tracking ใช้เลขที่เอกสารหรือ INV ตาม SOP ข้อ 4.1 |
| ผู้ส่ง | ✅ | |
| ชื่อผู้รับ | ✅ | |
| บริษัท | ✅ | เลือกจาก dropdown ที่มีในชีต |
| แผนกผู้รับ | ✅ | คัดแยกตาม SOP ข้อ 4.2 |
| มารับเอกสารเรียบร้อย | ❌ | **ทีมติ๊กเอง** ระบบไม่แตะ |
| ลงชื่อ ผู้รับเอกสาร | ❌ | **ทีมกรอกเอง** ระบบไม่แตะ |
| วันที่เข้ารับ | ❌ | **ทีมกรอกเอง** ระบบไม่แตะ |
| หมายเหตุ | ✅ | ใส่ข้อสังเกต เช่น ซองฉีก อ่านไม่ชัด |

เพิ่ม 2 ช่องต่อท้ายตาราง: **ลิงก์รูป** (กดแล้วเห็นรูปซอง) และ **รหัสไฟล์** (ซ่อนไว้ ใช้กันแถวซ้ำ)

## สีในชีตหมายความว่าอะไร

- **ช่องสีเหลือง** = ระบบอ่านช่องนั้นไม่ออก ให้กรอกเอง
- **ทั้งแถวสีแดง** = อ่านรูปไม่สำเร็จเลย หรือรูปไม่ชัดจนระบบไม่มั่นใจ ให้กรอกทั้งแถวเอง (แต่ยังมีลิงก์รูปให้กด)
- **ไม่มีสี** = ระบบมั่นใจ ดูผ่านๆ พอ

## ติดตั้ง (ทำครั้งเดียว)

### ส่วนที่ 1 — ขอ API key ของ Claude (5 นาที)

1. เข้า [console.anthropic.com](https://console.anthropic.com) → **API Keys** → **Create Key**
2. copy รหัสที่ได้เก็บไว้ (ขึ้นต้นด้วย `sk-ant-`)

### ส่วนที่ 2 — ทำให้ระบบอ่าน Slack ได้ (10 นาที)

1. เข้า [api.slack.com/apps](https://api.slack.com/apps) → **Create New App** → **From scratch**
2. ตั้งชื่อ เช่น `ทะเบียนเอกสาร` แล้วเลือก workspace ของ TDFB
3. เมนูซ้าย → **OAuth & Permissions** → เลื่อนหา **Bot Token Scopes** → **Add an OAuth Scope**
   ใส่ทีละอันให้ครบ 3 อัน:
   - `channels:history` (อ่านข้อความในห้อง)
   - `groups:history` (เผื่อห้องเป็นห้องส่วนตัว)
   - `files:read` (โหลดรูปได้)
4. เลื่อนขึ้นบนสุด → **Install to Workspace** → **Allow**
5. copy **Bot User OAuth Token** (ขึ้นต้นด้วย `xoxb-`) เก็บไว้
6. **สำคัญมาก** เปิด Slack ไปที่ห้อง `#parcel-opr` แล้วพิมพ์ `/invite @ทะเบียนเอกสาร`
   ถ้าไม่เชิญ bot เข้าห้อง ระบบจะอ่านไม่ได้
7. หา **Channel ID**: คลิกชื่อห้องด้านบน → เลื่อนลงล่างสุด → จะเห็น **Channel ID** ขึ้นต้นด้วย `C`

### ส่วนที่ 3 — วางโค้ดในชีต (5 นาที)

1. เปิดชีต → เมนู **ส่วนขยาย (Extensions)** → **Apps Script**
2. ลบโค้ดตัวอย่างที่มีอยู่ แล้ววางเนื้อหาจากไฟล์ `Code.gs` ในโฟลเดอร์นี้ทั้งหมด
3. กดรูปเฟือง **Project Settings** → เลื่อนลงหา **Script Properties** → **Add script property**
   ใส่ให้ครบ 3 ตัว:

   | ชื่อ | ค่าที่ใส่ |
   |---|---|
   | `ANTHROPIC_API_KEY` | รหัสจากส่วนที่ 1 (`sk-ant-...`) |
   | `SLACK_BOT_TOKEN` | รหัสจากส่วนที่ 2 ข้อ 5 (`xoxb-...`) |
   | `SLACK_CHANNEL_ID` | Channel ID จากส่วนที่ 2 ข้อ 7 (`C...`) |

4. กลับหน้า Editor → เลือกฟังก์ชัน **`setup`** จากช่อง dropdown → กด **Run**
   - ครั้งแรก Google จะขอสิทธิ์: **Review permissions** → เลือกบัญชี → **Advanced** → **Go to ... (unsafe)** → **Allow**
5. รีเฟรชชีต จะเห็นเมนูใหม่ **"ทะเบียนเอกสาร"** ด้านบน
6. กด **ทะเบียนเอกสาร → ตรวจการตั้งค่า** ควรขึ้นว่าทุกอย่างพร้อม รวมถึง `bot อยู่ในห้องแล้ว`

เสร็จแล้ว ระบบจะทำงานเองทุก 5 นาที

## ถ้าอยากดึงเดี๋ยวนี้ ไม่ต้องรอ

เมนู **ทะเบียนเอกสาร → ดึงเอกสารใหม่เดี๋ยวนี้**

## ถ้าอยากใช้ Drive แทน Slack

แก้บรรทัดบนสุดของ `Code.gs` จาก `var SOURCE = 'SLACK';` เป็น `var SOURCE = 'DRIVE';`
แล้วรัน `setup` ใหม่ ระบบจะสร้างโฟลเดอร์ให้อัปโหลดรูปแทน

## เจอปัญหา แก้ยังไง

| ข้อความที่ขึ้น | แปลว่า | ทำยังไง |
|---|---|---|
| `bot ยังไม่ได้อยู่ในห้อง` | ลืมเชิญ bot | ไปห้อง Slack พิมพ์ `/invite @ชื่อแอป` |
| `สิทธิ์ของ bot ไม่ครบ` | ใส่ scope ไม่ครบ 3 อัน | เพิ่ม scope แล้วกด **Reinstall to Workspace** |
| `token ไม่ถูกต้อง` | copy รหัสผิดตัว | ต้องเป็น **Bot User OAuth Token** ที่ขึ้นต้น `xoxb-` |
| `ไม่พบแท็บชื่อ ...` | ชื่อแท็บไม่ตรง | แก้ `var SHEET_NAME` ใน `Code.gs` ให้ตรงกับแท็บที่ใช้จริง |
| `ไม่มีหัวคอลัมน์ ...` | ชี้ผิดแท็บ หรือมีคนเปลี่ยนชื่อหัวตาราง | เช็คชื่อแท็บและหัวคอลัมน์ |

## ค่าใช้จ่าย

ประมาณ **0.01-0.02 USD ต่อรูป** ที่ปริมาณ ~30 ซอง/วัน = ราว **10-20 USD/เดือน**
Google Sheets / Drive / Apps Script / Slack ไม่มีค่าใช้จ่ายเพิ่ม

## สิ่งที่ระบบนี้ยัง**ไม่ได้**แก้

ช่อง **มารับเอกสารเรียบร้อย / ลงชื่อผู้รับ / วันที่เข้ารับ** ยังต้องกรอกมือเหมือนเดิม
ถ้าอยากได้ระบบที่บังคับให้กดรับพร้อมบันทึกชื่อและเวลาที่แก้ย้อนหลังไม่ได้
ต้องใช้เว็บแอปในโฟลเดอร์แม่ (`../`) ซึ่งใหญ่กว่านี้มาก
