# ระบบลงทะเบียนเอกสาร (สารบรรณ รับ-ส่ง)

ระบบลงทะเบียนเอกสารสำหรับเส้นทาง **ทีมคลังสินค้า → ทีม GM → ทีมบัญชี**
ใช้แทนการถ่ายรูปลง Slack + พิมพ์ลง Excel + ลงชื่อรับด้วยมือ

## ปัญหาที่ระบบนี้แก้

| ขั้นตอนเดิม | ปัญหา | ขั้นตอนใหม่ |
|---|---|---|
| คลังถ่ายรูปเอกสารลง Slack | รูปจมในแชท ค้นไม่ได้ ไม่ผูกกับทะเบียน | ถ่ายรูปในระบบ ได้เลขทะเบียนทันที รูปผูกกับเอกสารตลอดไป |
| ป๊อปพิมพ์ข้อมูลลง Excel เอง | พิมพ์ซ้ำจากรูป ช้า พิมพ์ผิดได้ | ระบบอ่านข้อมูลจากรูปมาให้ตรวจ (ถ้าเปิด AI) เหลือแค่ยืนยัน |
| ส่งเอกสารตัวจริงให้บัญชี | ไม่รู้ว่าเอกสารอยู่ในมือใคร | ใบส่งมอบเป็นชุด มีสถานะ real-time |
| บัญชีลงชื่อ+วันที่ใน Excel | ถ้าลืมลง = ไม่รู้ว่าใครรับ เมื่อไหร่ | บัญชีกดรับ ระบบบันทึกชื่อ+เวลาให้เอง แก้ย้อนหลังไม่ได้ |
| ตามเอกสารค้างด้วยการเดินถาม | ไม่มีใครรู้ภาพรวม | แดชบอร์ดเอกสารค้างแต่ละขั้น + แจ้งเตือน Slack |

Excel ไม่ได้หายไป — กดดาวน์โหลดไฟล์ `.xlsx` หน้าตาเดิมได้ทุกเมื่อ แต่ไม่ต้องมีใครมานั่งพิมพ์

## 4 สถานะของเอกสาร

```
INTAKE ──────► REGISTERED ─────► IN_TRANSIT ─────► ACCEPTED
คลังรับแล้ว     ลงทะเบียนแล้ว      ส่งบัญชีแล้ว        บัญชีรับแล้ว
รอลงทะเบียน     รอส่งบัญชี         รอบัญชีกดรับ
(ทีมคลัง)       (ทีม GM)          (ทีม GM)          (ทีมบัญชี)
```

ทุกการเปลี่ยนมือถูกบันทึกใน audit trail — ใคร ทำอะไร เมื่อไหร่ ดูได้จากหน้าทะเบียน

## สิทธิ์ตามบทบาท

| บทบาท | ทำได้ |
|---|---|
| `WAREHOUSE` ทีมคลังสินค้า | รับเอกสารเข้าระบบ (ถ่ายรูป + ออกเลขทะเบียน), ดูทะเบียน |
| `GM` ทีม GM (ป๊อป) | ลงทะเบียน/แก้ข้อมูล, สร้างใบส่งมอบ, รับเอกสารเข้าระบบ, ดูทะเบียน |
| `ACCOUNTING` ทีมบัญชี | กดรับเอกสารตามใบส่งมอบ, ดูทะเบียน |
| `ADMIN` | ทำได้ทุกอย่าง + สร้างผู้ใช้ |

## ติดตั้งและใช้งาน

ต้องมี **Node.js 22.5 ขึ้นไป** (ใช้ SQLite ที่มาในตัว Node ไม่ต้องลงฐานข้อมูลแยก)

```bash
npm install
npm run seed     # สร้างผู้ใช้ตั้งต้น 4 คน (แสดง PIN บนหน้าจอ — เปลี่ยนก่อนใช้จริง)
npm start        # เปิด http://localhost:3000
```

ทีมคลังเปิดจากมือถือได้เลย — หน้าเว็บออกแบบสำหรับมือถือเป็นหลัก และปุ่มแนบรูปเรียกกล้องหลังโดยตรง

### ตั้งค่าเพิ่มเติม (ไม่ใส่ก็ใช้งานได้)

คัดลอก `.env.example` เป็น `.env` แล้วเติมค่า:

| ตัวแปร | ผลที่ได้ |
|---|---|
| `SLACK_WEBHOOK_URL` | แจ้งเตือนเข้า Slack ทุกครั้งที่รับ / ลงทะเบียน / ส่งมอบ / บัญชีรับ |
| `ANTHROPIC_API_KEY` | ปุ่ม "อ่านข้อมูลจากรูป (AI)" ในหน้าลงทะเบียน — ดึงเลขที่เอกสาร วันที่ ผู้ส่ง ยอดเงิน จากรูปมาให้ตรวจ |
| `DATA_DIR` | ที่เก็บฐานข้อมูลและรูป (ค่าเริ่มต้น `./data`) |
| `PORT` | พอร์ตที่รัน (ค่าเริ่มต้น 3000) |

### แจ้งเตือนเอกสารค้างรายวัน

```bash
npm run notify   # สรุปเอกสารค้าง + รายการที่ค้างเกิน 24 ชม. ส่งเข้า Slack
```

ตั้ง cron ให้รันทุกเช้าวันทำการ:

```
0 9 * * 1-5  cd /path/to/doc-register && npm run notify
```

ปรับเกณฑ์ "ค้างนาน" ได้ด้วย `STALE_HOURS`

## โครงสร้างโค้ด

```
server/
  index.js            HTTP API + serve หน้าเว็บ
  db.js               schema SQLite + audit log
  auth.js             login ด้วย PIN, session cookie, ตรวจสิทธิ์ตามบทบาท
  seed.js             สร้างผู้ใช้ตั้งต้น
  notify-pending.js   สรุปเอกสารค้างเข้า Slack (สำหรับ cron)
  lib/
    regno.js          ออกเลขทะเบียน 69-0001 และรหัสใบส่งมอบ HO-690904-01
    ocr.js            อ่านข้อมูลจากรูปเอกสารด้วย Claude
    excel.js          สร้างไฟล์ .xlsx ของทะเบียน
    slack.js          ส่งข้อความเข้า Slack
    labels.js         ป้ายสถานะ/บทบาท และรูปแบบวันที่ไทย
public/
  index.html          เข้าสู่ระบบ + เมนูตามบทบาท
  intake.html         ทีมคลัง: ถ่ายรูปรับเอกสาร
  register.html       ทีม GM: ลงทะเบียน (มีปุ่มอ่านข้อมูลจากรูป)
  handover.html       ทีม GM: สร้าง/พิมพ์ใบส่งมอบ
  accounting.html     ทีมบัญชี: ตรวจรับเป็นชุด
  dashboard.html      ค้นหา สรุปเอกสารค้าง ดาวน์โหลด Excel
  app.js, style.css   โค้ดและสไตล์ที่ใช้ร่วมกัน (ไม่มีขั้นตอน build)
```

หน้าเว็บเป็น HTML + ES module ธรรมดา ไม่มี build step — แก้ไฟล์แล้ว refresh เห็นผลทันที

## หมายเหตุ

- ข้อมูลทั้งหมดอยู่ในไฟล์เดียวที่ `data/doc-register.db` และรูปที่ `data/uploads/` — สำรองข้อมูลด้วยการ copy โฟลเดอร์ `data/`
- ยังไม่มี HTTPS ในตัว ถ้าเปิดให้เข้าจากนอกออฟฟิศควรวางหลัง reverse proxy (nginx / Caddy / Cloudflare Tunnel)
- ฟีเจอร์อ่านรูปด้วย AI เปิด `fallbacks` ของ Claude API ไว้ เพื่อให้คำขอที่ถูกปฏิเสธถูกส่งต่อไปโมเดลสำรองอัตโนมัติ
